# EMU Assembly Manuals

This folder contains the step-by-step PDF assembly manuals for the EMU. The manuals are gradually replacing the [assembly videos](/docs/assembly_wiring/#assembly-videos) and are still a work in progress — new manuals are added here as they are finished.

They are meant to be read alongside the [Printing, Assembly and Wiring](/docs/assembly_wiring) page, which covers print settings, wiring and the printed parts configurator.
