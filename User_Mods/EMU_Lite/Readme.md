# EMU Lite

This is a simplified EMU.
<br><br>
It has no lid or base, but is fully compatible with the EMU Filamentelist and the hatch board.
<br><br>
Furthermore, it's possible to use wider motors that you might already have lying around.
<br><br>
A DXF file is included so you can design your own mount for your print. Alternatively, you can use the rubber feet from the repository.
